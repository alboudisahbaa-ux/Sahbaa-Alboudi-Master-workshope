# Advanced DDoS Attack Detection Project

## Welcome 👋

Welcome to this project repository for my Master degree letter.  
This work focuses on building an advanced system for detecting Distributed Denial-of-Service (DDoS) attacks using Machine Learning and Deep Learning techniques.

The project aims to analyze network traffic, extract meaningful features, and evaluate multiple models to achieve high-performance attack detection.

## Project Description
This project explores different machine learning and deep learning approaches for detecting DDoS attacks.  
It includes data preprocessing, feature engineering, model training, evaluation, and performance comparison.

- Detect DDoS attacks with high accuracy
- Compare multiple ML and DL models
- Improve network security using intelligent detection
